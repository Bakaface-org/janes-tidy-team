# Jane's Tidy Team

A professional home organization service website built with React, TypeScript, and Tailwind CSS. The site features a modern, responsive design with smooth scrolling navigation and optimized SEO.

## Features

- Single-page application with smooth scroll navigation
- Responsive design for all device sizes
- Service showcase with interactive carousel
- Process timeline
- Contact information and booking integration
- SEO optimized with semantic HTML structure

## Technology Stack

- React
- TypeScript
- Tailwind CSS
- Vite
- React Router
- Swiper for carousels
- Lucide React for icons
