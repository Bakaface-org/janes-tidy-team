# Jane's Tidy Team

A professional home organization service website built with React, TypeScript, and Tailwind CSS. The site features a modern, responsive design with smooth scrolling navigation and optimized SEO.

## Features

- Single-page application with smooth scroll navigation
- Responsive design for all device sizes
- Service showcase with interactive carousel
- Process timeline
- Contact information and booking integration
- SEO optimized with semantic HTML structure

## Technology Stack

- React
- TypeScript
- Tailwind CSS
- Vite
- React Router
- Swiper for carousels
- Lucide React for icons

## Random Organizing Tips

1. Use clear containers for better visibility
2. Label everything (yes, even your label maker)
3. The one-in-one-out rule keeps clutter at bay
4. Vertical space is your friend
5. Don't buy storage solutions before decluttering
6. Sort items into categories: Keep, Donate, Trash, Maybe
7. Take before and after photos for motivation
8. Set a timer for 15-minute organizing sessions
9. Store items where you use them
10. When in doubt, fold it vertically
